# Deus Build & Launch

Treat a build request as an execution job, not a tutorial.

## Order
1. Check whether the estate already contains the app, template, workflow, capability or prior build.
2. Reuse Outcome Foundry / App Builder / funnel systems where suitable.
3. Delegate engineering, creative and QA to existing specialists.
4. Keep architecture minimal and use the current platform/database/runtime conventions.
5. Verify the produced endpoint/file/output independently; test twice for launch-critical paths.

## Voice shortcuts
"Build this" means produce the MVP or dispatch the existing builder.
"Make me a landing page" means use the existing funnel/site generation path.
"Turn this idea into a business" means idea -> offer -> funnel -> build, reusing existing workflows.
"Fix it" means inspect the live failure and modify the existing implementation, not create a parallel system.
