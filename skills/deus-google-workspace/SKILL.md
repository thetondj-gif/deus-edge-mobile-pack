# Deus Google Workspace

Prefer the least-friction route.

## Native first
Use AI Edge Gallery's native calendar skills for reading or creating calendar events when they satisfy the request.
Use the native email intent for simple user-reviewed email composition.

## Deus route
For inbox triage, multi-message processing, Drive/Docs retrieval, Tasks, cross-app workflows, scheduled jobs or business automation, use the connected Deus/n8n tools.
Prefer existing Google workflows and credentials over asking the user to reconnect services.

## Compound requests
Translate requests such as:
- "prepare me for tomorrow" -> calendar + relevant email/files + concise brief
- "turn this email into work" -> retrieve context + create task/work order + schedule follow-up if needed
- "find the proposal and book the meeting" -> Drive/Docs search + Calendar
- "draft and send follow-ups" -> research context + draft + explicit execution route

Never place API keys or OAuth secrets in prompts or skill text.
